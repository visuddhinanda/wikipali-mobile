# 功能测试清单（真机）

面向 release 包的手工/半自动回归清单。上一轮只测了主干路径，这份把边界
和跨屏状态也列进来。**每一项都写了预期**，不写「看看对不对」。

## 0. 环境与驱动方式

容器没有 USB 透传，经宿主机的 adb server 驱动（详见 `STATUS.md` §12.3）：

```bash
export ADB_SERVER_SOCKET=tcp:127.0.0.1:5037
adb install -r android/app/build/outputs/apk/release/app-release.apk
adb shell am force-stop com.iapt.mobile
adb shell am start -n com.iapt.mobile/.MainActivity
adb logcat -c && adb logcat -v brief | grep -iE "ReactNativeJS|FATAL|sqlite"
```

取控件坐标：`adb shell uiautomator dump /sdcard/w.xml` 再读 `bounds`。

**注入点击的已知盲区**：

- 阅读页正文区（WebView）里的控件（如「就此段落提问」）收不到 `input tap`，
  只能人工点。
- 首次点击约三成会被吞，点第二次才生效 —— 判定「无响应」前至少点两次，
  并用 dump 比对界面是否真的没变。
- 底部 Tab 要点 y≈2300（更低会被手势导航条吃掉）。
- 小米需在开发者选项打开「USB 调试（安全设置）」，否则注入事件被拒。
